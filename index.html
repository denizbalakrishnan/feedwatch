    A brand-new video the modern method: a second model that can place a video nobody has watched

    The first model gives each video its own list of numbers, learned from who watched it. A video uploaded one second ago has no viewers, so it has no numbers. Feeds today add a second kind of model, a two-tower network, which works a video's numbers out from things known about it. Ours is given each video's tag, which the first model never sees.

        Real people the same code on data from a real short-video app

        Everything above uses a simulated crowd. This panel uses KuaiRec, a public record from the Kuaishou app: for 1,000 real people and 800 real videos, whether the app showed that person that video. The model gets that grid and nothing else. Each video's category is kept back to mark it with.

        We tried watch time first. In the part of KuaiRec where everyone saw every video, the typical viewer watched about 7.5 seconds of each one whatever its length, so watch time said almost nothing about topic (14% against 10% for guessing, measured offline). That is why the crowd on the first screen is simulated, and why we say so.

          Data: KuaiRec, Gao et al., CIKM 2022, shared under CC BY-SA 4.0. Our subsample keeps no captions, no user details and no original ID numbers.
